Date dan Time dalam input control adalah elemen antarmuka (UI) yang membantu
pengguna untuk memasukkan informasi tanggal dan waktu dengan cara yang mudah,
biasanya lewat tampilan kalender atau jam di aplikasi. 
Komponen yang digunakan; DatePicker atau DatePickerDialog untuk Date dan TimePicker atau TimePickerDialog
untuk Time.
Cara penggunannya, tinggal klik pada menu “Pilih Tanggal” lalu akan tersedia
tampilan kalender untuk setting. Berikut dengan menu “Pilih Waktu” tinggal klik
nanti akan muncul tampilan jam untuk setting, bisa juga input manual sesuaikan
dengan keinginan user yang terletak di bagian pojok kiri bawah.
